Static assets for tools that need them (showcase figures, sample data files, per-tool OG images).
Layout: site/public/tools/<tool-id>/<file>. Referenced from tool.json `showcase.figures[].src` (relative to this folder) or from a tool's README as /tools/<tool-id>/<file>.
Keep images ≤ 400 KB, 1600 px wide max, PNG/WebP. Sample data ≤ 1 MB. This README is not deployed as a page.
